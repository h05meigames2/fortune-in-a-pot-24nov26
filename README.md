One kind, funny fortune for a houseplant on the windowsill — written by a small
Python program (`main.py`, stdlib only, deterministic) for the
[Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9)
bounty on [make.fun](https://make.fun).

The program writes a single fortune line (109 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> Soon a new leaf will unfurl toward the sun, and your keeper will brag about you to every guest at the window.

## Run

```sh
python3 main.py
```
